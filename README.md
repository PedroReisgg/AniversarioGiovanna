# Feliz aniversário, Giovanna ♥

Site de presente feito para os 19 anos da Giovanna. HTML, CSS e JavaScript puros, com animações em GSAP.

## Como abrir
Ative o GitHub Pages em **Settings → Pages → Branch: main / (root)**. O site fica em
`https://pedroreisgg.github.io/AniversarioGiovanna/`.

## A música
O player toca `audio/iris-refrao.mp3`. Basta subir o arquivo com esse nome na pasta `audio/`.
